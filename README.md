# Secret Santa

A one-page Secret Santa draw. No sign-ups, no server, and nothing gets saved.

**Live page:** https://lucasishuman.github.io/santa/

## For the organizer

1. Open https://lucasishuman.github.io/santa/?organizer on your own computer.
2. Enter everyone's names, one per line.
3. Optionally, list people who shouldn't draw each other (one group per line, separated by commas).
4. Paste the page link into **Link to this page** so each message includes a ready-to-open link.
5. Click **Draw names**, then copy each person's message and send it only to them.

The page only shows codes, not who drew whom, so the organizer can take part too.

## For everyone else

Open the link you were sent (or paste your code into the page) and tap **Reveal my person**.

## How it works

Each code holds that person's name and the name they drew, scrambled so you can't read it at a glance. The page reads the code in your browser. Nothing is sent or stored anywhere.

Keep your code to yourself: anyone with your code can open it on the page and see who you drew. If the organizer draws again, the old codes still work, so make sure everyone gets their new message.
